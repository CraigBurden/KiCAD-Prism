# native/ — Prism's KiCad parser and design bundle (Rust)

Imported with its history from `krishna-swaroop/kicad_monkey` at `b6316117` (WP-F1). The design is `docs/architecture/adr-native-design-bundle.md`; the frozen contracts are TypeSpec in `src/tsp/prism/`, JSON Schema in `contracts/generated/schema/` and their examples, field maps and specs in `contracts/prism/` (start with `contracts/prism/README.md`).

- **Build and test** from this directory: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `cargo run -p prism-kicad-codegen -- --check` and `cargo deny check licenses sources` (`deny.toml`), on Rust 1.98.0 pinned by `rust-toolchain.toml`, plus `scripts/rust_hygiene.sh` (the size and complexity ratchet; `scripts/ci_native_hygiene.sh` is CI's wrapper). CI's `native-lint`, `native-workspace`, `native-hygiene` and `native-parity` jobs run them when `native/` changes.
- **Image:** `backend/Dockerfile`'s `prism-kicad-builder` stage builds only the `prism-kicad` binary, which the worker image ships as `/usr/local/bin/prism-kicad`, with `git-lfs` beside it.
- **Imported crates (MIT):** `src/rs/prism-kicad-*` (core, contracts, materialization-pack, svg, wasm, codegen, and transport, the fork's `kicad-monkey-native`). The imported `packages/kicad_cruncher/src/rs/kicad-cruncher-cli` was harvested into `prism-artwork`/`prism-vendors` and removed in WP-R2.
- **Prism crates (Apache-2.0):** `src/rs/prism-projections` (one module per projection, P1–P5), `src/rs/prism-artwork` (the NewStroke and default drawing-sheet facades over the core, C3 chunk C; chunk E adds the artwork views), `src/rs/prism-bundle` (the archive; `reader` feature without the parser, `build` with it; WP-B), `src/rs/prism-kicad-cli` (binary `prism-kicad`, WP-B), `src/rs/prism-vendors` (vendor BOM and placement outputs; C3) and `src/rs/prism-docs-lab` (hand-run documentation prototypes over a bundle, `net-class-atlas`; not Release Studio, `publish = false`).
- **Prism contracts:** check and build them with `node scripts/contracts/check-contract.mjs` and `node scripts/contracts/build.mjs` (Node 24.22.0; `contracts/prism/README.md`).
- **Fork contracts:** TypeSpec in `src/tsp/kicad_monkey/`, JSON Schema in `contracts/generated/schema/` (committed), Rust in `src/rs/prism-kicad-contracts/src/generated/` via `prism-kicad-codegen`. Never edit generated files by hand.
- **Licences:** MIT (`LICENSE`, Wavenumber LLC). `LICENSES.md` lists the third-party material per directory; `docs/architecture/native-provenance.md` records the sign-off.
- The imported `README.md`, `ARCHITECTURE.md` and `docs/` describe the fork, including its Python provider, which was not imported.
